# Intro to CTD-React-Todo-list
This project is a todo list created during CTD's React Class. It is a website that allows you to keep track of your to-do list. During the upcoming 11 weeks I will be creating a to-do list alongside my cohort. 

# Installation Instructions 
- To install this app, clone the repository
- Type npm install to download the dependency 
- Type npm run dev to run the app in the development server
